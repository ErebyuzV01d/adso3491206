01-Emmet

Lenguaje de marcado que estructura las páginas web.

01-Child: >
Creates child elements (nesting).

Example:

ul>li>a

Output:

<section></section> <header></header> <nav></nav>

02-Sibling: +
Creates sibling elements.

Example:

sectionheader+nav

Result:

<section></section> <header></header> <nav></nav>

03-Multiplication: *
Repeats elements multiple times.

Example:

ul>li*3

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class: .
Creates a class atribute.

Example:

menu.mainmenu

.container

Result:

<menu class="mainmenu"></menu> <div class="container"></div>

05-Classes: ...
Creates multiple class attributes.

Example:

menu.mainmenu.uppercase.blue

Result:

<menu class="mainmenu uppercase blue"></menu>

06-ID: #
Creates an ID attribute.

Example:

nav#1054859359

Result:

<nav id="1054859359"></nav>

07-Text: {}
Inserts text content.

Example:

h1{Lorem Ipsum Dolor}

h1{Click Here}

Result:

<h1>Lorem Ipsum Dolor.</h1> <a href="">Click Here</a>

08-Custom Attribute: []
Creates custom attributes.

Example:

a[href=www.youtube.com]

Result:

<a href="www.youtube.com"></a>

09-Item Numbering: $
Adds consecutive numbers.

Example:

ul>li.item*5

Result:

<ul> <li class="item1"></li> <li class="item2"></li> <li class="item3"></li> <li class="item4"></li> <li class="item5"></li> </ul>

10-Reverse Numbering
Reverses the numeration order.

Ejemplo:

ul>li.num$*3 ↔

section>article.sec$$$*3 ↔

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

11-Base Numbering
Defines a base number for secuencies.

Ejemplo:

ul>li.num$@3*4 ↔

Resultado:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up
Goes up a level.

Ejemplo:

section>article>div^p ↔

Resultado:

<section> <article> <div></div> <p></p> </article>

13-Grouping
Groups elements together.

Ejemplo:

(header>nav)+footer ↔

Resultado:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem
Generates lorem Ipsum.

Ejemplo:

lorem5 ↔

Resultado:

<p>Lorem ipsum dolor sit amet.</p>

15-HTML Documents
Creates some kinds of HTLM..

Ejemplo:

html:5

Resultado:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport"> <title>Document</title> </head> </html>

16-Meta Tags
Generates lorem Ipsum.

Ejemplo:

meta:vp

Resultado:

<meta name="viewport"
