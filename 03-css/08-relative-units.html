08-Relative-Units

Specify a length relative to another lenght property.

  • Pixel (px)
  • M (em)
  • X (ex)
  • Root M (rem)
  • Viewport Units Horizontal
  • Viewport Units Width (vm)
  • Large Viewport (lvh | lvw)
  • Small Viewport (svh | svw)
  • Dinamic Viewport (dvh | dvw)

Examples:

  • px: 15px
  • em: 1.5em
  • ex: 2ex
  • rem: 1.5rem
